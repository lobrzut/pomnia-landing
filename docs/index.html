Five steps to “Cursor remembers me”

Pięć kroków do „Cursor mnie pamięta”

  1. Ollama + models — install Ollama, then: 
    ollama pull nomic-embed-text    # required for search
ollama pull qwen2.5:14b         # required for distill
  2. Vault + backup — first-run wizard or Dashboard → create/open vault → Backup detected sources (Claude Code, Cursor, …).
  3. Distill — Brain tab → check Ollama → Distill backlog. Raw chats become condensed notes and a vector index.
  4. Connect (MCP) — Connect tab → pick embedded or remote → copy the snippet into Cursor → Reload Window. Details: MCP quickstart.
  5. Verify — Settings → Diagnostics should be green. In Cursor, ask about something from an older session — the agent should call search_library.
  1. Ollama + modele — zainstaluj Ollama, potem: 
    ollama pull nomic-embed-text    # wymagane do wyszukiwania
ollama pull qwen2.5:14b         # wymagane do distill
  2. Vault + backup — kreator albo Dashboard → utwórz/otwórz vault → Backup wykrytych źródeł (Claude Code, Cursor…).
  3. Distill — zakładka Brain → status Ollama → Distill backlog. Surowy czat → skondensowane notatki + indeks.
  4. Connect (MCP) — zakładka Connect → embedded lub remote → skopiuj snippet do Cursora → Reload Window. Szczegóły: MCP quickstart.
  5. Weryfikacja — Settings → Diagnostyka na zielono. W Cursorze zapytaj o coś ze starej sesji — agent powinien wołać search_library.

Brain modes

Tryby Brain

  • Embedded (recommended to start) — Brain inside Pomnia on 127.0.0.1:7862. Needs Ollama on the same machine.
  • Remote (homelab) — your Brain server on LAN. Needs Bearer token + MCP proxy. Always configure three servers: pomnia, pomnia-vault, pomnia-library.
  • Embedded (zalecane na start) — Brain w Pomni na 127.0.0.1:7862. Ollama na tej samej maszynie.
  • Remote (homelab) — serwer Brain w LAN. Token Bearer + proxy MCP. Zawsze trzy serwery: pomnia, pomnia-vault, pomnia-library.
