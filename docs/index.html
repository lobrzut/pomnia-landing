Three boxes — that’s the whole picture

Trzy pudełka — cały obraz

  • Your folder (Vault) — briefcase on disk you pick; sealed chat archives + plain notes beside them.
  • Search card (Index) — rebuildable catalog on this PC so agents find things fast; plaintext, not sealed by the vault password.
  • The app — unlocks the folder, builds the catalog, opens the MCP door to any agent.
  • Twój folder (Sejf) — teczka na dysku, którą wybierasz; zamknięte archiwum czatów + zwykłe notatki obok.
  • Karta katalogowa (Indeks) — odtwarzalny katalog na tym PC, żeby agenci szybko znajdowali treść; plaintext, hasło vaultu go nie zamyka.
  • Aplikacja — otwiera folder, buduje katalog, drzwi MCP do dowolnego agenta.

Five steps until your agents remember you

Pięć kroków, aż agenci Cię zapamiętają

  1. Ollama + models — install Ollama, then: 
    ollama pull nomic-embed-text    # required for search
ollama pull qwen2.5:14b         # required for distill
  2. Vault + backup — first-run wizard or Dashboard → create/open vault → Backup detected sources (Claude Code, Cursor, …).
  3. Distill — prepare memory from the backlog (Brain tab → Distill). Raw chats become condensed notes + search card entries.
  4. Connect (MCP) — Connect tab → on this machine (default) or your server → copy the snippet into Cursor → Reload Window. Details: MCP quickstart.
  5. Verify — Settings → Diagnostics should be green. In Cursor, ask about something from an older session — the agent should call search_library. Red rows: Troubleshooting.
  1. Ollama + modele — zainstaluj Ollama, potem: 
    ollama pull nomic-embed-text    # wymagane do wyszukiwania
ollama pull qwen2.5:14b         # wymagane do distill
  2. Vault + backup — kreator albo Dashboard → utwórz/otwórz vault → Backup wykrytych źródeł (Claude Code, Cursor…).
  3. Distill — przygotuj pamięć z backlogu (zakładka Brain → Distill). Surowy czat → skondensowane notatki + wpisy w karcie katalogowej.
  4. Connect (MCP) — zakładka Connect → na tej maszynie (domyślnie) lub Twój serwer → skopiuj snippet do Cursora → Reload Window. Szczegóły: MCP quickstart.
  5. Weryfikacja — Settings → Diagnostyka na zielono. W Cursorze zapytaj o coś ze starej sesji — agent powinien wołać search_library. Czerwone wiersze: Rozwiązywanie problemów.

Where search runs

Gdzie działa wyszukiwanie

  • On this machine (start here) — search inside Pomnia on 127.0.0.1:7862. Needs Ollama locally.
  • On your server (later / homelab) — remote search + Bearer token. Wiring details: Connect MCP.
  • Na tej maszynie (zacznij tu) — wyszukiwanie w Pomni na 127.0.0.1:7862. Ollama lokalnie.
  • Na Twoim serwerze (później / homelab) — zdalne wyszukiwanie + token Bearer. Podłączenie: Podłącz MCP.

  • Cloud vault sync
