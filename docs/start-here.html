Start here

Pomnia is a local app: one encrypted vault for assistant conversations, then Brain so agents (Cursor and friends) can recall context over MCP. Nothing leaves your machine until you deliberately point it at a server you run.

Adapted from product docs/START-HERE.md — public, short, accurate. In the app, the Polish How it works map covers the same flow.
Windows installer is unsigned. SmartScreen may say “Windows protected your PC” — choose More info → Run anyway. Prefer verifying the installer hash from the GitHub release assets when published.

Two stores — don’t mix them up

NameWhereHolds
Pomnia Vault Folder you choose (e.g. C:\Vault) Encrypted chats + docs (+ skills, USER.md, distilled notes…)
Brain data %AppData%/Pomnia/brain-core-data/ RAG index (library.db) + distill notes — on-disk, not vault-encrypted

Vault = archive and backup. Brain data = semantic search engine.

Five steps to “Cursor remembers me”

1. Download & install

Get the latest Windows build from GitHub Releases. Early public / alpha — feedback welcome at hello@pomnia.ai.

2. Ollama + models

Install Ollama, run it, then pull:

ollama pull nomic-embed-text    # embeddings — required for search
ollama pull qwen2.5:14b         # chat distill — required for distill

3. Vault + backup

  • First-run wizard or Dashboard → create/open a vault.
  • Backup — select detected sources (Claude Code, Cursor, …) → Backup.

4. Distill

Brain tab → check Ollama status → Distill backlog. Raw chat logs become condensed .md notes and a vector index.

5. Connect MCP & verify

See Connect MCP. Then Settings → Diagnostics — Ollama, models, vault, brain-core, MCP should be green. Ask Cursor about something from an earlier session; it should call search_library.

Brain modes (short)

  • Embedded (default) — Brain inside Pomnia on 127.0.0.1:7862; needs Ollama on this machine.
  • Remote (homelab) — your Brain on LAN; Bearer token + MCP proxy. Pick the mode in Connect before copying the snippet.

Backup vs Import

  • Backup — live assistant files on disk (Claude Code, Cursor, …).
  • Import — ZIP/JSON exports (Claude.ai, ChatGPT, Gemini, …) or single files.

If Cursor backup shows 0 chats — use Import.

Not in this alpha yet

  • Signed installer (SmartScreen / Gatekeeper)
  • Linux installer / full macOS ship
  • Cloud vault sync
