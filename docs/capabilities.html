What Pomnia can do

Co Pomnia potrafi

Pomnia is a portable encrypted-archive memory layer plus MCP so agents can search and write that memory. It is not an agent product and not a cloud chat app.

Pomnia to przenośna warstwa pamięci z zaszyfrowanym archiwum plus MCP, żeby agenci mogli szukać i dopisywać tę pamięć. To nie produkt-agent i nie chmurowy czat.

Positioning: Desktop = chrome + ops (vault, backup, distill, Connect). Agents type through MCP (pomnia). Memory you own — not a wrapper around Cursor/Claude.
Pozycjonowanie: Desktop = chrome + ops (vault, backup, distill, Connect). Agenci piszą przez MCP (pomnia). Pamięć, którą posiadasz — nie wrapper wokół Cursora/Claude.

What it does

Co robi

  • Vault create / unlock / lock — pick a folder (any name, including *.pomnia); AES-256-GCM blobs for chat/document archives; passphrase via scrypt. Lock clears the key from RAM — it does not wipe the search index. Details: Where is my data? · Architecture.
  • Backup live assistants — Claude Code, Cursor, Claude Desktop, Antigravity, VS Code / Windsurf, Continue (hybrid or snapshot per source).
  • Import — ZIP/JSON exports (Claude.ai, ChatGPT, Gemini, Grok) and documents (PDF, DOCX, EPUB). Sparse PDFs: thin OCR (tesseract, eng+pol) then direct index — not distill.
  • Distill — Ollama turns chats into condensed markdown notes (Summary / Decisions / …) and feeds the search card. You start it; it is not a silent daemon. Pipeline: How memory works. Who runs what: Automation.
  • Search — hybrid semantic + keyword over distilled notes + library. In-app (Chats / Brain) and via MCP search_library. Index lives as plaintext library.db under AppData (rebuildable).
  • Connect MCP — snippet for Cursor (and other MCP clients). Default: embedded Brain on 127.0.0.1:7862. Advanced: remote / homelab Brain + Bearer. Connect MCP.
  • MCP tools in tools/list — search_library (compact hits by default), read_note (full text of one hit, by path), save_conversation (only on “save to Pomnia” / „zapisz do Pomnia”), checkpoint_session (milestones when auto-checkpoint is ON), get_user_profile, memory (USER.md), library_status, list_skills / get_skill (and deprecated list_cli_skills), list_prompts / get_prompt.
  • Profile & skills — vault USER.md (person patterns) + optional AGENTS.md; plaintext skills/ workflows agents can load. Handshake phrase = agent proof that MCP is wired, not a Desktop unlock ritual.
  • Portable vault — copy the whole vault folder to another PC → Open vault → password. Export distilled notes from the UI / CLI.
  • Desktop chrome — PL|EN UI, tray (close/minimize to tray), Diagnostics, notify-only update check (GitHub Releases — no silent auto-install), floating “How it works” diagram (live distill / index / MCP status — not a session recorder).
  • CLI — headless scan / doctor / backup / list / verify, same engine as Desktop. No CLI binary ships in a release. From a source checkout: npm run cli (tsx src/cli/index.ts).
  • Vault: utwórz / odblokuj / zablokuj — wybierasz folder (dowolna nazwa, też *.pomnia); bloby AES-256-GCM na archiwa czatów/dokumentów; hasło przez scrypt. Lock czyści klucz z RAM — nie kasuje indeksu wyszukiwania. Szczegóły: Gdzie są dane? · Architektura.
  • Backup żywych asystentów — Claude Code, Cursor, Claude Desktop, Antigravity, VS Code / Windsurf, Continue (hybrid lub snapshot zależnie od źródła).
  • Import — eksporty ZIP/JSON (Claude.ai, ChatGPT, Gemini, Grok) oraz dokumenty (PDF, DOCX, EPUB). Sparse PDF: thin OCR (tesseract, eng+pol), potem bezpośredni indeks — bez distill.
  • Distill — Ollama zamienia czaty w skondensowane notatki markdown (Summary / Decisions / …) i karmi kartę katalogową. Ty to uruchamiasz; to nie cichy demon. Pipeline: Jak działa pamięć. Kto co robi: Automatyzacja.
  • Wyszukiwanie — hybrydowe (semantyka + słowa kluczowe) po notatkach distill + bibliotece. W aplikacji (Czaty / Brain) i przez MCP search_library. Indeks = plaintext library.db w AppData (odtwarzalny).
  • Connect MCP — snippet do Cursora (i innych klientów MCP). Domyślnie: embedded Brain na 127.0.0.1:7862. Zaawansowane: remote / homelab + Bearer. Podłącz MCP.
  • Narzędzia MCP w tools/list — search_library (domyślnie skrócone trafienia), read_note (pełny tekst jednego trafienia, po ścieżce), save_conversation (tylko na „zapisz do Pomnia” / “save to Pomnia”), checkpoint_session (milestone gdy auto-checkpoint ON), get_user_profile, memory (USER.md), library_status, list_skills / get_skill (oraz deprecated list_cli_skills), list_prompts / get_prompt.
  • Profil i skills — vault USER.md (wzorce osoby) + opcjonalnie AGENTS.md; plaintext skills/ do ładowania przez agentów. Fraza Handshake = dowód, że MCP działa — nie rytuał odblokowania Desktopu.
  • Przenośny vault — skopiuj cały folder na inny PC → Open vault → hasło. Eksport notatek distill z UI / CLI.
  • Chrome Desktop — UI PL|EN, tray (zamknięcie/minimalizacja do traya), Diagnostyka, sprawdzenie aktualizacji tylko jako powiadomienie (GitHub Releases — bez cichej instalacji), pływający diagram „Jak to działa” (live distill / indeks / MCP — nie rejestrator sesji).
  • CLI — headless scan / doctor / backup / list / verify, ten sam silnik co Desktop. W wydaniu nie ma binarki CLI. Ze źródeł: npm run cli (tsx src/cli/index.ts).

What it does not

Czego nie robi

  • Not an agent — no orchestration harness, no “run my agents for me.” Agents live in Cursor / Claude / … and call Pomnia for memory.
  • Not a cloud chat — no Pomnia-hosted conversations; no vendor cloud required for the default path.
  • Does not silently capture live IDE chats — adapters read stores only when you Backup / Distill / Import. Full dump needs the save phrase; see Automation.
  • Password ≠ full-disk secrecy — distilled notes, skills/, USER.md, sessions, and library.db are plaintext on disk by design. Lock ≠ wipe index.
  • Not signed yet — Windows SmartScreen may warn; expected for early public builds.
  • Not listed, and not implemented: run_skill, search_code, code_status. They are absent from tools/list. A client that calls one anyway gets a refusal: nothing ran, and the text points at get_skill, search_library, or library_status.
  • Not yet: cloud vault sync, code signing on any platform, silent auto-update install, full OCR of every PDF page. Linux Desktop .AppImage / .deb are on GitHub Releases. That is not the headless brain-core server tarball. macOS Mini does not exist. Linux Mini PomniaMini-linux-x64.AppImage is the stable name from the next release on — see Updates & install.
  • Nie jest agentem — bez harnessu orkiestracji, bez „uruchom mi agentów”. Agenci żyją w Cursorze / Claude / … i wołają Pomnię po pamięć.
  • Nie jest chmurowym czatem — brak rozmów hostowanych przez Pomnię; domyślna ścieżka nie wymaga chmury vendora.
  • Nie podsłuchuje cicho żywych czatów IDE — adaptery czytają store dopiero przy Backup / Distill / Import. Pełny dump wymaga frazy zapisu; zob. Automatyzacja.
  • Hasło ≠ pełna tajemnica dysku — notatki distill, skills/, USER.md, sessions i library.db są plaintext na dysku by design. Lock ≠ wipe indeksu.
  • Jeszcze bez podpisu — SmartScreen na Windows może ostrzec; normalne dla wczesnego publica.
  • Nie ma ich na liście i nie są zaimplementowane: run_skill, search_code, code_status. Nie występują w tools/list. Klient, który i tak je wywoła, dostaje odmowę: nic nie ruszyło, a tekst wskazuje get_skill, search_library albo library_status.
  • Jeszcze nie: sync vault do chmury, podpis kodu na żadnej platformie, cicha auto-instalacja update, pełny OCR wszystkich stron PDF. Linux Desktop .AppImage / .deb — na GitHub Releases. To nie tarball serwera brain-core. Mini na macOS nie istnieje. Linux Mini PomniaMini-linux-x64.AppImage to stabilna nazwa od następnego wydania — zob. Aktualizacje i instalacja.
