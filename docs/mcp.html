Embedded (Pomnia app on this machine)

Embedded (aplikacja Pomnia na tej maszynie)

Local Brain inside Pomnia = one MCP server on http://127.0.0.1:7862/mcp, no Bearer token.

Lokalny Brain w Pomni = jeden serwer MCP na http://127.0.0.1:7862/mcp, bez tokena Bearer.

  1. Open Pomnia → Connect → mode Embedded.
  2. Copy the Cursor snippet → paste into ~/.cursor/mcp.json (or merge carefully).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: server pomnia should show Connected.
  1. Pomnia → Connect → tryb Embedded.
  2. Skopiuj snippet Cursora → wklej do ~/.cursor/mcp.json (albo zmerguj ostrożnie).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: serwer pomnia = Connected.

Remote (homelab Brain)

Remote (Brain w homelabie)

Always configure three client keys. A lone pomnia entry is incomplete (legacy keys brain-rag / brain-vault / brain-library still work in status checks).

Zawsze trzy klucze po stronie klienta. Sam pomnia = niepełna konfiguracja (legacy brain-rag / brain-vault / brain-library status jeszcze akceptuje).

pomnia/sse
pomnia-vault/servers/brain-vault/sse

Klucz MCPŚcieżka na proxy Brain
pomnia/sse

pomnia-library/servers/brain-library/sse

Token: Brain dashboard on :7860 (same host as MCP, different port) → Settings / API tokens. MCP itself is on :7862.

Token: dashboard Brain na :7860 (ten sam host, inny port) → Settings / API tokens. Sam MCP: :7862.

Template (replace host + token)

Szablon (podstaw host + token)

{
  "mcpServers": {
    "pomnia": {
      "url": "http://YOUR-HOST:7862/sse",
      "headers": { "Authorization": "Bearer btk_…" }
    },
    "pomnia-vault": {
      "url": "http://YOUR-HOST:7862/servers/brain-vault/sse",
      "headers": { "Authorization": "Bearer btk_…" }
    },
    "pomnia-library": {
      "url": "http://YOUR-HOST:7862/servers/brain-library/sse",
      "headers": { "Authorization": "Bearer btk_…" }
    }
  }
}

Do not commit a real token. On macOS: chmod 600 ~/.cursor/mcp.json.

Nie commituj prawdziwego tokena. Na macOS: chmod 600 ~/.cursor/mcp.json.

Verify

Weryfikacja

  • Cursor → Settings → MCP: three servers Connected (remote) or one (embedded).
  • Ask the agent something only your vault knows — it should call get_user_profile / search_library.
  • Cursor → Settings → MCP: trzy serwery Connected (remote) albo jeden (embedded).
  • Zapytaj agenta o coś tylko z Twojego vaultu — powinien wołać get_user_profile / search_library.
