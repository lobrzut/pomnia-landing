Connect MCP

Podłącz MCP

Wire Cursor (or any MCP client) to Pomnia Brain so agents can call search_library / get_user_profile against your memory.

Podłącz Cursor (lub inny klient MCP) do Brain Pomni, żeby agenci wołali search_library / get_user_profile na Twojej pamięci.

Prefer the in-app Connect tab in Pomnia Desktop — Windows, macOS, and Linux. It copies a ready snippet. This page is the manual map. Folder vs search card: Where is my data? · pipeline: How memory works · auto-checkpoint vs phrase: Automation · paths: Architecture.
Użyj zakładki Connect w Pomnia Desktop — Windows, macOS i Linux. Kopiuje gotowy snippet. Ta strona to mapa ręczna. Folder vs indeks: Gdzie są dane? · pipeline: Jak działa pamięć · auto-checkpoint vs fraza: Automatyzacja · ścieżki: Architektura.

Embedded (Pomnia app on this machine)

Embedded (aplikacja Pomnia na tej maszynie)

Local Brain inside Pomnia = one MCP server on http://127.0.0.1:7862/mcp, no Bearer token.

Lokalny Brain w Pomni = jeden serwer MCP na http://127.0.0.1:7862/mcp, bez tokena Bearer.

  1. Open Pomnia → Connect → mode Embedded.
  2. Copy the Cursor snippet → paste into ~/.cursor/mcp.json (or merge carefully).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: server pomnia should show Connected.
  1. Pomnia → Connect → tryb Embedded.
  2. Skopiuj snippet Cursora → wklej do ~/.cursor/mcp.json (albo zmerguj ostrożnie).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: serwer pomnia = Connected.

Remote — brain-core (homelab / Linux server)

Remote — brain-core (homelab / serwer Linux)

Same engine as Desktop embed, headless via systemd/Docker. One MCP server key pomnia → http://YOUR-HOST:7865/mcp. :7865 is the install.sh default (--port). :7862 is the daemon default, used by Desktop’s embedded Brain. Bearer token required. Admin/status: same host /admin and /healthz — not a separate :7860 dashboard. Details: Linux self-hosted.

Ten sam silnik co embed w Desktop, headless przez systemd/Docker. Jeden klucz MCP pomnia → http://YOUR-HOST:7865/mcp. :7865 to domyślny port install.sh (--port). :7862 to domyślny port demona, używany przez wbudowany Brain Desktopu. Wymagany Bearer. Admin/status: ten sam host /admin i /healthz — bez osobnego dashboardu :7860. Szczegóły: Linux self-hosted. 

{
  "mcpServers": {
    "pomnia": {
      "url": "http://YOUR-HOST:7865/mcp",
      "headers": { "Authorization": "Bearer btk_…" }
    }
  }
}

Token: printed once by install.sh, or issued under /var/lib/pomnia/mcp-tokens.json / admin panel. Do not commit a real token. On Linux/macOS: chmod 600 ~/.cursor/mcp.json.

Token: raz z install.sh, albo z /var/lib/pomnia/mcp-tokens.json / panelu admin. Nie commituj prawdziwego tokena. Linux/macOS: chmod 600 ~/.cursor/mcp.json.

First install: panel login is admin, password in /var/lib/pomnia/admin-initial-password (mode 600). The printed token is named first and has role agent (no role field means agent). Put that agent token in the MCP snippet. Skills, prompts, and a sync push into a vault this host owns need a separate admin token — write_needs_admin. There is no brain-core command on PATH:

Pierwsza instalacja: login panelu to admin, hasło w /var/lib/pomnia/admin-initial-password (tryb 600). Wypisany token nazywa się first i ma rolę agent (brak pola roli oznacza agenta). Ten token agenta wstaw do snippetu MCP. Skills, prompty i push sync do vaultu, którego właścicielem jest ten host, wymagają osobnego tokenu admin — write_needs_admin. Na PATH nie ma komendy brain-core: 

sudo -u pomnia node /opt/pomnia-brain-core/dist/daemon.js \
  --data-dir /var/lib/pomnia \
  --add-token desktop --role admin
sudo -u pomnia node /opt/pomnia-brain-core/dist/daemon.js \
  --data-dir /var/lib/pomnia \
  --add-token desktop --role admin

The server’s own error string says brain-core --add-token <name> --role admin. Use the node …/dist/daemon.js line instead. Full notes: Linux self-hosted.

Własny tekst błędu serwera mówi brain-core --add-token <name> --role admin. Użyj linii node …/dist/daemon.js. Pełne notatki: Linux self-hosted.

Connect emits this shape. Desktop → Connect → Remote generates the single /mcp server above. Pasting by hand works too — the template is here so you can check what Connect produced.
Connect generuje właśnie ten kształt. Desktop → Connect → Remote daje pojedynczy serwer /mcp powyżej. Wklejenie ręczne też zadziała — szablon jest tu po to, żebyś mógł sprawdzić, co Connect wygenerował.

Footnote. Older copies of this page showed three SSE servers (pomnia, pomnia-vault, pomnia-library on /sse). That was the retired Python hub. It is not a setup path, and Connect does not emit it. Those paths no longer answer. A config that still lists the extra keys fails at the next client restart with an error that names none of this — delete them and keep the single pomnia server above.

Przypis. Starsze kopie tej strony pokazywały trzy serwery SSE (pomnia, pomnia-vault, pomnia-library na /sse). To był wycofany hub Python. To nie jest ścieżka setupu i Connect tego nie generuje. Te ścieżki już nie odpowiadają. Konfiguracja, która nadal ma dodatkowe klucze, pada przy następnym restarcie klienta błędem, który o tym nie mówi — usuń je i zostaw jeden serwer pomnia powyżej.

Verify

Weryfikacja

  • Cursor → Settings → MCP: one server pomnia Connected (embedded or brain-core).
  • Ask the agent something only your vault knows — it should call get_user_profile / search_library.
  • Cursor → Settings → MCP: jeden serwer pomnia Connected (embedded / brain-core).
  • Zapytaj agenta o coś tylko z Twojego vaultu — powinien wołać get_user_profile / search_library.
