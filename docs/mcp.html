Embedded (Pomnia app on this machine)

Embedded (aplikacja Pomnia na tej maszynie)

Local Brain inside Pomnia = one MCP server on http://127.0.0.1:7862/mcp, no Bearer token.

Lokalny Brain w Pomni = jeden serwer MCP na http://127.0.0.1:7862/mcp, bez tokena Bearer.

  1. Open Pomnia → Connect → mode Embedded.
  2. Copy the Cursor snippet → paste into ~/.cursor/mcp.json (or merge carefully).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: server pomnia should show Connected.
  1. Pomnia → Connect → tryb Embedded.
  2. Skopiuj snippet Cursora → wklej do ~/.cursor/mcp.json (albo zmerguj ostrożnie).
  3. Cursor → Command Palette → Developer: Reload Window.
  4. Settings → MCP: serwer pomnia = Connected.

Remote — brain-core (homelab / Linux server)

Remote — brain-core (homelab / serwer Linux)

Same engine as Desktop embed, headless via systemd/Docker. One MCP server key pomnia → http://YOUR-HOST:7865/mcp (port is whatever you set; :7865 is common when :7862 is busy). Bearer token required. Admin/status: same host /admin and /healthz — not a separate :7860 dashboard. Details: Linux self-hosted.

Ten sam silnik co embed w Desktop, headless przez systemd/Docker. Jeden klucz MCP pomnia → http://YOUR-HOST:7865/mcp (port jak w unicie; :7865 typowe gdy :7862 zajęte). Wymagany Bearer. Admin/status: ten sam host /admin i /healthz — bez osobnego dashboardu :7860. Szczegóły: Linux self-hosted. 

{
  "mcpServers": {
    "pomnia": {
      "url": "http://YOUR-HOST:7865/mcp",
      "headers": { "Authorization": "Bearer btk_…" }
    }
  }
}

Token: printed once by install.sh, or issued under /var/lib/pomnia/mcp-tokens.json / admin panel. Do not commit a real token. On Linux/macOS: chmod 600 ~/.cursor/mcp.json.

Token: raz z install.sh, albo z /var/lib/pomnia/mcp-tokens.json / panelu admin. Nie commituj prawdziwego tokena. Linux/macOS: chmod 600 ~/.cursor/mcp.json.

Connect emits this shape by default. Desktop → Connect → Remote generates the single /mcp server below; the legacy three-key SSE form is opt-in and only for a Python hub that is still running. Pasting by hand works too — the template is here so you can check what Connect produced rather than trust it.
Connect domyślnie generuje właśnie ten kształt. Desktop → Connect → Remote daje pojedynczy serwer /mcp poniżej; legacy trzy klucze SSE to opcja na żądanie, wyłącznie dla hubów Pythona, które jeszcze działają. Wklejenie ręczne też zadziała — szablon jest tu po to, żebyś mógł sprawdzić, co Connect wygenerował, a nie wierzyć mu na słowo.

Legacy remote — Python hub (3× SSE)

Legacy remote — hub Python (3× SSE)

Older Reliqua/Python Brain behind a supergateway. Kept for hubs still running it; Connect → Remote defaults to brain-core. Always three client keys (legacy names brain-rag / brain-vault / brain-library still pass status checks). Token from dashboard :7860; MCP proxy usually :7862.

Stary hub Reliqua/Python za supergateway. Zostaje dla hubów, które go jeszcze mają; Connect → Remote domyślnie daje brain-core. Zawsze trzy klucze (legacy brain-rag / brain-vault / brain-library status jeszcze akceptuje). Token z dashboardu :7860; MCP zwykle :7862.

Verify

Weryfikacja

  • Cursor → Settings → MCP: one server Connected (embedded or brain-core), or three (legacy Python hub).
  • Ask the agent something only your vault knows — it should call get_user_profile / search_library.
  • Cursor → Settings → MCP: jeden serwer Connected (embedded / brain-core) albo trzy (legacy hub Python).
  • Zapytaj agenta o coś tylko z Twojego vaultu — powinien wołać get_user_profile / search_library.
