Where is my data?

Gdzie są moje dane?

Hold this in twenty seconds: a folder you pick, a search card on this PC, and the app that opens the door. Under the hood there are more moving parts — for premiere, these three are enough.

Zapamiętaj w dwadzieścia sekund: folder, który wybierasz, karta katalogowa na tym PC i aplikacja, która otwiera drzwi. Pod spodem jest więcej kółek — na premierę wystarczą te trzy.

1 · Vault

Your folder

The briefcase on disk: sealed chat/doc archives plus plain notes you (and agents) edit — skills, profile, sessions.

Path you choose
e.g. C:\Vault or ~/Vault

→ ↓
2 · Index

Search card

A rebuildable catalog so recall is fast. Plaintext chunk text + embeddings — not sealed by the vault password.

This machine only
%AppData%/pomnia
~/Library/Application Support/pomnia
~/.config/pomnia

Door + MCP

Pomnia unlocks the folder, builds the catalog, and lets Cursor (or any MCP client) ask questions.

3 · Aplikacja

Drzwi + MCP

Pomnia otwiera folder, buduje katalog i pozwala Cursorowi (lub innemu klientowi MCP) zadawać pytania.

Aplikacja desktop
wyszukiwanie lokalne na :7862

Honest, short. The vault password seals archive blobs only. Notes in the vault folder and the search index are readable if someone can read your disk. Lock clears the key from RAM — it does not wipe the index. Details: Privacy.
Uczciwie, krótko. Hasło vaultu zamyka tylko bloby archiwum. Notatki w folderze vaultu i indeks wyszukiwania da się przeczytać przy dostępie do dysku. Lock czyści klucz z RAM — nie kasuje indeksu. Szczegóły: Privacy.

What you can ignore for now

Co na razie możesz olać

  • Internal folder names under AppData, remote search servers — power-user layer.
  • Distill vs direct document index — both feed the same search card; start with Backup → Distill. Deep dive: How memory works.
  • Full unlock/lock mechanics: Architecture.
  • Wewnętrzne nazwy pod AppData, zdalne serwery wyszukiwania — warstwa power-user.
  • Distill vs indeks dokumentów — oba karmią tę samą kartę katalogową; zacznij od Backup → Distill. Deep dive: Jak działa pamięć.
  • Pełna mechanika unlock/lock: Architektura.

Jedna ścieżka na pierwszy tydzień
