Linux self-hosted

Linux self-hosted

Two Linux paths: the server one-liner (headless AGPL brain-core + systemd) and Linux Desktop GUI (AppImage or deb). Same memory product — not a cloud service.

Dwie ścieżki Linux: one-liner serwera (headless AGPL brain-core + systemd) oraz Linux Desktop GUI (AppImage albo deb). Ten sam produkt pamięci — nie chmura.

Server path (this page’s one-liner). Headless brain-core on Linux x64 + systemd — MCP memory you host. Not the Desktop AppImage/deb, not Windows.
Ścieżka serwera (one-liner na tej stronie). Headless brain-core na Linux x64 + systemd — pamięć MCP, którą hostujesz. To nie AppImage/deb Desktopu i nie Windows.

Linux server (brain-core)

Serwer Linux (brain-core)

curl -fsSL https://pomnia.ai/install.sh | sh
curl -fsSL https://pomnia.ai/install.sh | sh

Needs Node 22 at /usr/bin/node (systemd ExecStart=/usr/bin/node in the current tarball — nvm-only PATH is not enough), systemd, and x86_64. Script fetches pomnia-brain-core-*-linux-x64.tar.gz from GitHub Latest and runs the packaged installer. Optional: | sh -s -- --with-ollama.

Wymaga Node 22 pod /usr/bin/node (jednostka systemd w tarballu: ExecStart=/usr/bin/node — samo nvm nie wystarczy), systemd i x86_64. Skrypt pobiera pomnia-brain-core-*-linux-x64.tar.gz z GitHub Latest i odpala instalator z pakietu. Opcjonalnie: | sh -s -- --with-ollama.

Defaults

Domyślne

Inside the tarball, deploy/install.sh defaults to --port 7865, BRAIN_EMBED_BACKEND=fastembed (in-process ONNX, about 0.5 GB, no Ollama), and BRAIN_DISTILL=0. Search works without a chat model. Distillation stays off. --with-ollama sets embeddings to Ollama and BRAIN_DISTILL=1, including the nightly distill timer.

W tarballu deploy/install.sh domyślnie ustawia --port 7865, BRAIN_EMBED_BACKEND=fastembed (ONNX w procesie, około 0.5 GB, bez Ollamy) i BRAIN_DISTILL=0. Wyszukiwanie działa bez modelu czatu. Destylacja jest wyłączona. --with-ollama przełącza embeddingi na Ollamę i ustawia BRAIN_DISTILL=1, razem z nocnym timerem distill.

The daemon’s own default port — what Desktop’s embedded Brain uses — is 7862. 7865 is the install.sh default, not the daemon default. The published install.sh is a mirror of packages/brain-core/deploy/bootstrap.sh at commit 1cfae03. It checks that node on PATH is 22 or newer. The unit’s ExecStart is /usr/bin/node, so that path has to be Node 22. nvm alone is invisible to systemd. The wrapper does not add a second check the product script does not have.

Własny domyślny port demona — ten, którego używa wbudowany Brain Desktopu — to 7862. 7865 jest domyślne dla install.sh, nie dla demona. Publikowany install.sh jest kopią packages/brain-core/deploy/bootstrap.sh z commita 1cfae03. Sprawdza, że node na PATH ma 22 albo więcej. ExecStart jednostki to /usr/bin/node, więc ta ścieżka musi być Node 22. Samo nvm jest dla systemd niewidoczne. Wrapper nie dokłada drugiego sprawdzenia, którego nie ma skrypt produktu.

First login

Pierwsze logowanie

The installer creates a panel account admin. The password is random and written once to /var/lib/pomnia/admin-initial-password (mode 600). Read it, sign in at http://<host>:7865/admin, change it (Konta → Hasło), then delete the file. There is no admin/changeme.

Instalator zakłada konto panelu admin. Hasło jest losowe i zapisane raz do /var/lib/pomnia/admin-initial-password (tryb 600). Odczytaj je, zaloguj się na http://<host>:7865/admin, zmień je (Konta → Hasło) i usuń plik. Nie ma admin/changeme.

The first bearer token is named first, printed once, and stored without a role. A token with no role is an agent. It can call MCP, including search_library and save_conversation. It cannot edit skills or prompts, and it cannot push sync or archive writes into a vault this host owns (write_needs_admin). From the next release, the packaged installer and the container image put brain-core on PATH at /usr/local/bin/brain-core. Use that:

Pierwszy token bearer nazywa się first, jest wypisany raz i zapisany bez roli. Token bez roli to agent. Może wołać MCP, w tym search_library i save_conversation. Nie może edytować skills ani promptów i nie może pchać zapisu sync ani archiwum do vaultu, którego właścicielem jest ten host (write_needs_admin). Od następnego wydania instalator w tarballu i obraz kontenera kładą brain-core na PATH pod /usr/local/bin/brain-core. Użyj tego: 

brain-core --add-token desktop --role admin
brain-core --add-token desktop --role admin

The wrapper runs dist/daemon.js as user pomnia with --data-dir /var/lib/pomnia, and calls sudo if you are not that user. The current release (v0.1.91) has no brain-core command. On an install from before that change, use the long form:

Wrapper uruchamia dist/daemon.js jako użytkownik pomnia z --data-dir /var/lib/pomnia i woła sudo, jeśli nie jesteś tym użytkownikiem. Bieżące wydanie (v0.1.91) nie ma komendy brain-core. Na instalacji sprzed tej zmiany użyj długiej formy: 

sudo -u pomnia node /opt/pomnia-brain-core/dist/daemon.js \
  --data-dir /var/lib/pomnia \
  --add-token desktop --role admin
sudo -u pomnia node /opt/pomnia-brain-core/dist/daemon.js \
  --data-dir /var/lib/pomnia \
  --add-token desktop --role admin

Re-running the installer does not rotate the token or the password.

Ponowne uruchomienie instalatora nie rotuje tokenu ani hasła.

Linux Desktop GUI

Linux Desktop GUI

AppImage or deb on GitHub Latest — the Electron desktop, same as Windows. Unsigned: verify SHA-256. This is not the curl server installer.

AppImage albo deb na GitHub Latest — Electron Desktop, jak Windows. Niepodpisane: weryfikuj SHA-256. To nie jest instalator serwera z curl.

Mini is a third thing. Not this Desktop AppImage, and not the server. No macOS Mini. Linux Mini, from the next release, is the stable asset PomniaMini-linux-x64.AppImage. The current Latest tag (v0.1.91) does not contain it, so that URL returns HTTP 404 until then. Its settings directory is ~/.config/pomnia-mini, not ~/.config/pomnia. Windows Mini today is PomniaMini-<version>.zip on Latest — that page is the link that works now. From the next release the stable name is PomniaMini-win-x64.zip. v0.1.91 does not contain it, so that URL returns HTTP 404 until then.

Mini to trzecia rzecz. Nie ten AppImage Desktopu i nie serwer. Mini na macOS nie ma. Linux Mini, od następnego wydania, to stabilny asset PomniaMini-linux-x64.AppImage. Bieżący tag Latest (v0.1.91) go nie zawiera, więc ten URL zwraca HTTP 404 do tego czasu. Katalog ustawień to ~/.config/pomnia-mini, nie ~/.config/pomnia. Windows Mini dziś to PomniaMini-<version>.zip na Latest — ta strona działa już teraz. Od następnego wydania stabilna nazwa to PomniaMini-win-x64.zip. v0.1.91 go nie zawiera, więc ten URL zwraca HTTP 404 do tego czasu.

Who owns the vault

Kto jest właścicielem vaultu

You — the folder on disk. Pomnia does not create a cloud account. Desktop and a headless brain-core server must not both write the same folder.

Ty — folder na dysku. Pomnia nie zakłada konta w chmurze. Desktop i headless brain-core nie mogą jednocześnie pisać do tego samego folderu.

  1. Desktop → server: quit Desktop writes → sync/copy vault → start server with vault root (claim if your unit supports it) → point agents at the server URL.
  2. Server → Desktop: stop server writes / read-only → copy vault → Open vault on Desktop → reindex local library.db.
  1. Desktop → serwer: zatrzymaj zapis Desktopu → skopiuj vault → uruchom serwer z vault root → skieruj agentów na URL serwera.
  2. Serwer → Desktop: zatrzymaj zapis serwera / read-only → skopiuj vault → Otwórz vault na Desktopie → reindeksuj lokalne library.db.

App data vs vault (plaintext honesty)

Dane aplikacji vs vault (uczciwość plaintext)

  • ~/.config/pomnia — settings, logs, brain-core-data/…/library.db (search index: plaintext, rebuildable).
  • Vault folder — encrypted blobs + plaintext knowledge sidecars (USER.md, distilled/, …).
  • Lock does not wipe the index. Uninstall does not delete vault or XDG data.
  • ~/.config/pomnia — ustawienia, logi, brain-core-data/…/library.db (indeks wyszukiwania: plaintext, odbudowywalny).
  • Folder vaultu — zaszyfrowane bloby + plaintext sidecary wiedzy (USER.md, distilled/, …).
  • Lock nie kasuje indeksu. Odinstalowanie nie kasuje vaultu ani danych XDG.

In the app: Settings → Where data lives shows the live paths. Also: Where is my data?

W aplikacji: Ustawienia → Gdzie leżą dane pokazuje żywe ścieżki. Też: Gdzie są moje dane?

Updates (no fake auto-update)

Aktualizacje (bez fałszywego auto-update)

Settings → Check for updates asks GitHub. If newer: open Releases. Replace the AppImage file or dpkg -i the new deb yourself. Same notify-only story as Windows — no silent install.

Ustawienia → Sprawdź aktualizacje pyta GitHuba. Gdy nowsze: otwórz Releases. Podmień AppImage albo dpkg -i nowy deb sam. Ta sama historia notify-only co Windows — bez cichej instalacji.

Uninstall / wipe

Odinstalowanie / wipe

  • Delete AppImage or apt remove / dpkg -r — app gone; data stays.
  • Wipe machine data: rm -rf ~/.config/pomnia
  • Wipe memory: delete/move the vault folder (and optionally the index).
  • Usuń AppImage lub apt remove / dpkg -r — aplikacja znika; dane zostają.
  • Wipe danych maszyny: rm -rf ~/.config/pomnia
  • Wipe pamięci: usuń/przenieś folder vaultu (i opcjonalnie indeks).

Ollama & Connect

Ollama i Connect

Install Ollama for your distro, start it, then pull nomic-embed-text (search) and llama3.1:8b (distill default), or use in-app pull. Connect snippets for Cursor live under ~/.config/Cursor/… — single interactive user honesty (tokens name agents/machines, not Desktop seats).

Zainstaluj Ollamę pod swoją dystrybucję, uruchom, potem pobierz nomic-embed-text (wyszukiwanie) i llama3.1:8b (domyślny distill) — albo przyciskiem w aplikacji. Snippety Connect dla Cursora: ~/.config/Cursor/… — jeden użytkownik interaktywny (tokeny nazywają agentów/maszyny, nie „miejsca” Desktopu).
