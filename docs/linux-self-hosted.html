Linux self-hosted

Linux self-hosted

AGPL Desktop on Linux is AppImage or deb plus a folder you own. Same product as Windows — not a cloud service. Unsigned builds: verify SHA-256.

AGPL Desktop na Linuxie to AppImage albo deb oraz folder, który jest Twój. Ten sam produkt co Windows — nie chmura. Buildy niepodpisane: weryfikuj SHA-256.

Who owns the vault

Kto jest właścicielem vaultu

You — the folder on disk. Pomnia does not create a cloud account. Desktop and a headless brain-core server must not both write the same folder.

Ty — folder na dysku. Pomnia nie zakłada konta w chmurze. Desktop i headless brain-core nie mogą jednocześnie pisać do tego samego folderu.

  1. Desktop → server: quit Desktop writes → sync/copy vault → start server with vault root (claim if your unit supports it) → point agents at the server URL.
  2. Server → Desktop: stop server writes / read-only → copy vault → Open vault on Desktop → reindex local library.db.
  1. Desktop → serwer: zatrzymaj zapis Desktopu → skopiuj vault → uruchom serwer z vault root → skieruj agentów na URL serwera.
  2. Serwer → Desktop: zatrzymaj zapis serwera / read-only → skopiuj vault → Otwórz vault na Desktopie → reindeksuj lokalne library.db.

App data vs vault (plaintext honesty)

Dane aplikacji vs vault (uczciwość plaintext)

  • ~/.config/Pomnia — settings, logs, brain-core-data/…/library.db (search index: plaintext, rebuildable).
  • Vault folder — encrypted blobs + plaintext knowledge sidecars (USER.md, distilled/, …).
  • Lock does not wipe the index. Uninstall does not delete vault or XDG data.
  • ~/.config/Pomnia — ustawienia, logi, library.db (indeks: plaintext, odbudowywalny).
  • Folder vaultu — zaszyfrowane bloby + plaintext sidecary wiedzy.
  • Lock nie kasuje indeksu. Odinstalowanie nie kasuje vaultu ani danych XDG.

In the app: Settings → Where data lives shows the live paths. Also: Where is my data?

W aplikacji: Ustawienia → Gdzie leżą dane pokazuje żywe ścieżki. Też: Gdzie są moje dane?

Updates (no fake auto-update)

Aktualizacje (bez fałszywego auto-update)

Settings → Check for updates asks GitHub. If newer: open Releases. Replace the AppImage file or dpkg -i the new deb yourself. Same notify-only story as Windows — no silent install.

Ustawienia → Sprawdź aktualizacje pyta GitHuba. Gdy nowsze: otwórz Releases. Podmień AppImage albo dpkg -i nowy deb sam. Ta sama historia notify-only co Windows — bez cichej instalacji.

“Self-hosted” means your machine or VPS — Desktop alone counts. The server is the headless twin, not a different product.

„Self-hosted” = Twoja maszyna lub VPS — sam Desktop wystarcza. Serwer to headless bliźniak, nie inny produkt.

Uninstall / wipe

Odinstalowanie / wipe

  • Delete AppImage or apt remove / dpkg -r — app gone; data stays.
  • Wipe machine data: rm -rf ~/.config/Pomnia
  • Wipe memory: delete/move the vault folder (and optionally the index).
  • Usuń AppImage lub apt remove — aplikacja znika; dane zostają.
  • Wipe danych maszyny: rm -rf ~/.config/Pomnia
  • Wipe pamięci: usuń/przenieś folder vaultu (i opcjonalnie indeks).

Ollama & Connect

Ollama i Connect

Install Ollama for your distro, start it, then use in-app pull for embed/chat models. Connect snippets for Cursor live under ~/.config/Cursor/… — single interactive user honesty (tokens name agents/machines, not Desktop seats).

Zainstaluj Ollamę pod swoją dystrybucję, uruchom, potem pobierz modele przyciskiem w aplikacji. Snippety Connect dla Cursora: ~/.config/Cursor/… — jeden użytkownik interaktywny (tokeny nazywają agentów/maszyny, nie „miejsca” Desktopu).
