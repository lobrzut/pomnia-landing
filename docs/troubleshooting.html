Start with Diagnostics

Zacznij od Diagnostyki

Settings → Diagnostics should go green for: Ollama, required models, vault open, brain-core / embedded Brain, MCP reachable. Fix red rows top-down before hunting exotic bugs.

Settings → Diagnostyka na zielono: Ollama, wymagane modele, otwarty vault, brain-core / embedded Brain, MCP osiągalny. Napraw czerwone od góry — zanim szukasz egzotyki. 

ollama pull nomic-embed-text    # search / embed
ollama pull qwen2.5:14b         # distill (or your chosen chat model)

Symptom → fix

Symptom → naprawa

SymptomWhat to do
Distill won’t start / stays idle Ollama offline or distill model missing — Brain → Pull model; confirm Ollama is running on this PC (embedded).
Search returns nothing / empty Brain Need nomic-embed-text, then Refresh index / distill so the search card has chunks. Folder full ≠ index built.
Cursor MCP “Not connected” / Partial Copy snippet from Connect; merge into ~/.cursor/mcp.json; Reload Window. Embedded = one /mcp. brain-core remote = one :7865/mcp + Bearer (manual if Connect still emits legacy 3×SSE). Legacy Python hub = three SSE keys + Bearer.
Agent never calls Pomnia tools Handshake / rules must mention MCP pomnia. Ask something only your vault knows. See Connect MCP → Verify.
0 chats after Cursor backup Huge state.vscdb often fails live backup — use Import (export ZIP/JSON) instead of the live adapter path.
SmartScreen / AV on setup.exe Expected for unsigned builds — Updates & install. Do not disable AV.
Installer “cannot be closed” Tray → Quit Pomnia, dismiss setup, run again (NSIS replaces Pomnia.exe).
Forgot passphrase No recovery key from us — vault blobs stay sealed. Sidecar notes / index on disk are separate; see Privacy.
Update check silent / “unreachable” Offline, proxy, or GitHub rate limit — check Releases in the browser. App never auto-installs.
SymptomCo zrobić
Distill nie startuje / stoi Ollama offline albo brak modelu distill — Brain → Pull model; Ollama musi działać na tym PC (embedded).
Search puste / Brain nic nie zwraca Potrzebujesz nomic-embed-text, potem Refresh index / distill, żeby karta katalogowa miała chunki. Pełny folder ≠ zbudowany indeks.
Cursor MCP „Not connected” / Partial Snippet z Connect → ~/.cursor/mcp.json → Reload Window. Embedded = jeden /mcp. Remote brain-core = jeden :7865/mcp + Bearer (ręcznie, jeśli Connect nadal daje legacy 3×SSE). Legacy hub Python = trzy klucze SSE + Bearer.
Agent nie woła narzędzi Pomni Handshake / reguły muszą wskazywać MCP pomnia. Zapytaj o coś tylko z vaultu. Zobacz Podłącz MCP → Weryfikacja.
0 czatów po backupie Cursora Duży state.vscdb często pada na live backup — użyj Import (ZIP/JSON) zamiast ścieżki live adaptera.
SmartScreen / AV na setup.exe Norma dla niepodpisanych buildów — Aktualizacje i instalacja. Nie wyłączaj AV.
Installer „nie da się zamknąć” Tray → Quit Pomnia, zamknij setup, odpal ponownie (NSIS podmienia Pomnia.exe).
Zapomniane hasło Nie mamy recovery key — bloby vaultu zostają zamknięte. Sidecary / indeks na dysku to osobna sprawa; Privacy.
Update check cichy / „unreachable” Offline, proxy albo limit GitHuba — sprawdź Releases w przeglądarce. Aplikacja nigdy nie instaluje sama.

Backup vs Import (short)

Backup vs Import (krótko)

Backup = live adapters reading known app paths on this machine. Import = you bring a file (ZIP / JSON / MD). When live Cursor backup returns empty, prefer Import from an export — don’t keep retrying the same live path.

Backup = live adaptery czytające znane ścieżki aplikacji na tej maszynie. Import = Ty dostarczasz plik (ZIP / JSON / MD). Gdy live backup Cursora wraca pusty — wolisz Import z eksportu; nie spammuj tą samą ścieżką live.
