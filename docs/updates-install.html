Updates & install

Aktualizacje i instalacja

Windows installer from GitHub. Builds are unsigned at premiere — SmartScreen is expected. Updates are notify-only: you download the next setup yourself.

Instalator Windows z GitHuba. Buildy premiere są niepodpisane — SmartScreen to norma. Aktualizacje są tylko powiadomieniem: kolejny setup pobierasz sam.

Trust posture (encryption, no telemetry): Privacy · stuck after install: Troubleshooting · first run: Start here.
Zaufanie (szyfrowanie, brak telemetry): Privacy · utknąłeś po instalacji: Rozwiązywanie problemów · pierwszy start: Zacznij tutaj.

Download

Pobieranie

  1. Open GitHub Releases → Latest.
  2. Take the one for your machine: Pomnia-x.y.z-setup.exe (Windows, NSIS), Pomnia-x.y.z-arm64.dmg (Apple Silicon) or -x64.dmg (Intel Mac), Pomnia-x.y.z.AppImage / .deb (Linux desktop). uname -m names your Mac.
  3. Run it. Vault path and passphrase stay yours — the installer does not invent a cloud account.
  1. Otwórz GitHub Releases → Latest.
  2. Weź plik dla swojej maszyny: Pomnia-x.y.z-setup.exe (Windows, NSIS), Pomnia-x.y.z-arm64.dmg (Apple Silicon) albo -x64.dmg (Mac Intel), Pomnia-x.y.z.AppImage / .deb (Linux desktop). uname -m mówi, który Mac.
  3. Uruchom. Ścieżka vaultu i hasło zostają u Ciebie — instalator nie zakłada konta w chmurze.

Pomnia Mini

Pomnia Mini

Thin client. No embedded Brain, no Ollama, no local distill, no local search index. Connect it to a remote brain-core you already run. The vault stays on that server. Mini keeps its own settings directory, pomnia-mini, so it does not share Desktop’s pomnia folder (settings and vault pointer). Windows: %AppData%\pomnia-mini. macOS: ~/Library/Application Support/pomnia-mini. Linux: ~/.config/pomnia-mini. Logs sit in logs under that directory.

Cienki klient. Bez wbudowanego Brain, bez Ollamy, bez lokalnego distill, bez lokalnego indeksu. Łączysz go ze zdalnym brain-core, które już prowadzisz. Vault zostaje na tym serwerze. Mini trzyma własny katalog ustawień, pomnia-mini, więc nie dzieli z Desktopem folderu pomnia (ustawienia i wskaźnik vaultu). Windows: %AppData%\pomnia-mini. macOS: ~/Library/Application Support/pomnia-mini. Linux: ~/.config/pomnia-mini. Logi są w logs w tym katalogu.

Windows, today. On GitHub Releases → Latest, take PomniaMini-<version>.zip (the version matches that release). Unpack once and run PomniaMini.exe. Not the portable exe, and not PomniaMini-<version>-portable.zip (that older zip unpacks into %TEMP% on every launch). Not the Desktop installer Pomnia-<version>-setup.exe. A stable asset name PomniaMini-win-x64.zip is planned in the product repo. It is not on the current Latest release, so this page does not link it. When a release actually contains that file, the same Latest page will list it.

Windows, dziś. Na GitHub Releases → Latest weź PomniaMini-<version>.zip (wersja zgadza się z tym wydaniem). Rozpakuj raz i uruchom PomniaMini.exe. To nie portable exe i nie PomniaMini-<version>-portable.zip (ten starszy zip wypakowuje się do %TEMP% przy każdym starcie). To nie instalator Desktop Pomnia-<version>-setup.exe. Stabilna nazwa PomniaMini-win-x64.zip jest planowana w repozytorium produktu. Nie ma jej w bieżącym Latest, więc ta strona do niej nie linkuje. Gdy wydanie naprawdę ją zawiera, ta sama strona Latest ją pokaże.

Linux, from the next release. The stable asset name is PomniaMini-linux-x64.AppImage. It is not on the current Latest release (v0.1.91 has no Mini AppImage), so that URL returns HTTP 404 until the next release is published. It is not the Desktop Pomnia-<version>.AppImage. chmod +x, then run it. No macOS Mini.

Linux, od następnego wydania. Stabilna nazwa assetu to PomniaMini-linux-x64.AppImage. Nie ma jej w bieżącym Latest (v0.1.91 nie ma Mini AppImage), więc ten URL zwraca HTTP 404, dopóki nie wyjdzie następne wydanie. To nie Desktop Pomnia-<version>.AppImage. chmod +x, potem uruchom. Mini na macOS nie ma.

Unsigned & SmartScreen

Bez podpisu i SmartScreen

Open-source Windows builds ship without Authenticode for now. Each new setup.exe hash starts at zero reputation — Windows SmartScreen and some AVs warn. That is expected noise, not a malware verdict.

Buildy open-source na Windows idą na razie bez Authenticode. Każdy nowy hash setup.exe ma zerową reputację — SmartScreen i część AV ostrzegają. To oczekiwany szum, nie werdykt „wirus”.

  • SmartScreen: More info → Run anyway.
  • Do not turn off antivirus to “make install work.” Trust the file once if you chose to install from our release.
  • Folder exclusions only if AV keeps quarantining the install directory or vault — workaround, not the product goal.
  • Long-term fix: code signing (tracked in the product repo).

macOS is unsigned too, and stricter about it. Sequoia removed the old Control-click → Open bypass for unsigned apps, so there is no macOS equivalent of “Run anyway”: open Pomnia, let the block appear, then System Settings → Privacy & Security → Open Anyway. If you would rather clear the quarantine flag yourself, do it only after checking the SHA-256: 

xattr -dr com.apple.quarantine /Applications/Pomnia.app
  • SmartScreen: Więcej informacji → Uruchom mimo to.
  • Nie wyłączaj antywirusa, żeby „instalacja przeszła”. Ufaj plikowi raz, jeśli celowo instalujesz z naszego release.
  • Wykluczenia folderu tylko gdy AV wciąż kwarantannuje katalog instalacji albo vault — obejście, nie cel produktu.
  • Docelowo: podpis kodu (tracked w repo produktu).

macOS też jest bez podpisu i traktuje to ostrzej. Sequoia usunęła dawne obejście Control-click → Otwórz dla aplikacji bez podpisu, więc odpowiednika „Uruchom mimo to” nie ma: otwórz Pomnię, pozwól blokadzie się pokazać, potem Ustawienia systemowe → Prywatność i ochrona → Otwórz mimo to. Jeśli wolisz sam zdjąć flagę kwarantanny, zrób to dopiero po sprawdzeniu SHA-256: 

xattr -dr com.apple.quarantine /Applications/Pomnia.app

Verify the installer

Weryfikacja instalatora

Every asset in a release ships a matching .sha256 beside it, and the release notes repeat the digests. Download only from github.com/lobrzut/pomnia/releases — do not trust mirrored copies.

Każdy plik w wydaniu ma obok siebie .sha256, a notatki wydania powtarzają sumy. Pobieraj wyłącznie z github.com/lobrzut/pomnia/releases; nie ufaj lustrzanym kopiom. 

Get-FileHash .\Pomnia-x.y.z-setup.exe -Algorithm SHA256    # Windows
shasum -a 256 Pomnia-x.y.z-arm64.dmg                       # macOS
sha256sum Pomnia-x.y.z.AppImage                            # Linux

Compare the digest to the published value character-for-character.

Porównaj digest ze opublikowaną wartością znak po znaku.

What latest.yml is (and is not)

Czym jest latest.yml (a czym nie)

Release packaging may include latest.yml / .blockmap beside the exe (electron-builder metadata). That does not mean Pomnia silently downloads and installs updates.

Przy release mogą leżeć latest.yml / .blockmap obok exe (metadane electron-buildera). To nie znaczy, że Pomnia cicho pobiera i instaluje update.

Updating

Aktualizacja

  1. When the app says a newer release exists (or you check Releases yourself), download the new setup.exe.
  2. Quit Pomnia fully (tray → Quit) so NSIS can replace files.
  3. Run the new installer over the old one. Your vault folder is not wiped by a normal upgrade.
  1. Gdy aplikacja zgłosi nowszy release (albo sam sprawdzisz Releases), pobierz nowy setup.exe.
  2. Wyjdź z Pomni do końca (tray → Quit), żeby NSIS mógł podmienić pliki.
  3. Odpal nowy instalator na starej instalacji. Zwykły upgrade nie kasuje folderu vaultu.

If setup says the app “cannot be closed”: Quit from the tray, close the installer dialog, try again.

Jeśli setup mówi, że aplikacji „nie da się zamknąć”: Quit z tray, zamknij dialog instalatora, spróbuj ponownie.
