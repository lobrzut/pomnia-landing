Download

Pobieranie

The files are on GitHub Releases → Latest. This page names them. It does not pin a version in the URL, because a versioned asset link returns HTTP 404 on the next tag.

Pliki są na GitHub Releases → Latest. Ta strona je nazywa. Nie wpina wersji w URL, bo link do assetu z numerem wersji zwraca HTTP 404 przy następnym tagu.

Desktop

Desktop

  • Windows: Pomnia-<version>-setup.exe. Unsigned. SmartScreen is expected. More info → Run anyway.
  • macOS: Pomnia-<version>-arm64.dmg (Apple Silicon) or Pomnia-<version>-x64.dmg (Intel). Unsigned. There is no “Run anyway”.
  • Linux desktop: Pomnia-<version>.AppImage or .deb. Unsigned. This is not the server and not Mini.
  • Windows: Pomnia-<version>-setup.exe. Bez podpisu. SmartScreen jest oczekiwany. Więcej informacji → Uruchom mimo to.
  • macOS: Pomnia-<version>-arm64.dmg (Apple Silicon) albo Pomnia-<version>-x64.dmg (Intel). Bez podpisu. Nie ma „Uruchom mimo to”.
  • Linux desktop: Pomnia-<version>.AppImage albo .deb. Bez podpisu. To nie serwer i nie Mini.

Check the .sha256 published next to the file. Details: Updates & install.

Sprawdź .sha256 opublikowane obok pliku. Szczegóły: Aktualizacje i instalacja.

Pomnia Mini

Pomnia Mini

Thin client. No embedded Brain, no Ollama, no local distill, no local search index. It connects to a brain-core you already run. Settings live in pomnia-mini, not Desktop’s pomnia: %AppData%\pomnia-mini, ~/Library/Application Support/pomnia-mini, ~/.config/pomnia-mini.

Cienki klient. Bez wbudowanego Brain, bez Ollamy, bez lokalnego distill, bez lokalnego indeksu. Łączy się z brain-core, które już prowadzisz. Ustawienia są w pomnia-mini, nie w Desktopowym pomnia: %AppData%\pomnia-mini, ~/Library/Application Support/pomnia-mini, ~/.config/pomnia-mini.

Windows, today. On Latest, take PomniaMini-<version>.zip. Unpack once and run PomniaMini.exe. Not PomniaMini-<version>-portable.zip (that zip unpacks into %TEMP% on every launch) and not Pomnia-<version>-setup.exe. A stable name PomniaMini-win-x64.zip is planned. It is not on the current release, so this page does not link it.

Windows, dziś. Na Latest weź PomniaMini-<version>.zip. Rozpakuj raz i uruchom PomniaMini.exe. To nie PomniaMini-<version>-portable.zip (ten zip wypakowuje się do %TEMP% przy każdym starcie) i nie Pomnia-<version>-setup.exe. Stabilna nazwa PomniaMini-win-x64.zip jest planowana. Nie ma jej w bieżącym wydaniu, więc ta strona do niej nie linkuje.

Linux, from the next release. Stable asset: PomniaMini-linux-x64.AppImage. The current Latest tag (v0.1.91) does not contain it, so the URL returns HTTP 404 until that release exists. Not the Desktop Pomnia-<version>.AppImage. chmod +x, then run it. No macOS Mini.

Linux, od następnego wydania. Stabilny asset: PomniaMini-linux-x64.AppImage. Bieżący tag Latest (v0.1.91) go nie zawiera, więc URL zwraca HTTP 404, dopóki to wydanie nie istnieje. To nie Desktop Pomnia-<version>.AppImage. chmod +x, potem uruchom. Mini na macOS nie ma.

Linux server

Serwer Linux

curl -fsSL https://pomnia.ai/install.sh | sh
curl -fsSL https://pomnia.ai/install.sh | sh

Headless brain-core, not the AppImage. Node 22 on PATH, and /usr/bin/node for the systemd unit. Default port 7865. Linux self-hosted.

Bezgłowy brain-core, nie AppImage. Node 22 na PATH i /usr/bin/node dla jednostki systemd. Domyślny port 7865. Linux self-hosted.
