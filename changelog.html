Release notes

Noty wydań

Release notes live on GitHub Releases, on the tag marked Latest. This site does not duplicate them.

Noty wydań są na GitHub Releases, na tagu oznaczonym Latest. Ta witryna ich nie dubluje.

A copied changelog on pomnia.ai drifted before (versioned Mini links, partial digests). The notes for a tag are whatever that release page says, including the SHA-256 lines published with the assets. What to install, and which names survive a version bump, is on Download.

Skopiowany changelog na pomnia.ai wcześniej się rozjeżdżał (linki Mini z wersją, niepełne skróty). Notatki tagu to to, co mówi strona tego wydania, łącznie z liniami SHA-256 przy assetach. Co zainstalować i które nazwy przeżywają podbicie wersji, jest na stronie Pobieranie.

There is no /changelog feed separate from GitHub. /changelog and this page say the same thing.

Nie ma kanału /changelog osobnego od GitHuba. /changelog i ta strona mówią to samo.
